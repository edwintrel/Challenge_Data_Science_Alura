# 🧠 Challenge de Data Science - Decisión de Venta de Tienda

Este proyecto forma parte de un **challenge promovido por Alura**, enfocado en el **análisis de datos para la toma de decisiones comerciales**.  
El objetivo principal es **determinar cuál de cuatro tiendas es la más conveniente para vender**.

---

## 📊 Descripción del proyecto

Se proporcionaron **cuatro bases de datos**, una por cada tienda, con información sobre:

- Producto y Categoría: Artículos vendidos y sus calificaciones.
- Precio y Envío: Valores de venta y costos asociados.
- Fecha y ubicación de compra: Información temporal y geográfica.
- Evaluación de compra: Comentarios de clientes.
- Tipo de Pago y Cuotas: Métodos utilizados por los clientes.
- Coordenadas Geográficas: Ubicación de las transacciones.

El análisis se realizó utilizando **Python en Google Colab**, aprovechando librerías especializadas para el manejo y visualización de datos como:

- **Pandas** → Para la carga, limpieza, transformación y análisis de los datos.
- **Matplotlib** → Para la creación de gráficos y visualizaciones que facilitan la interpretación de los resultados.

---

## 🧩 Objetivos del análisis

El proyecto busca responder la pregunta:
> ¿En cuál de las cuatro tiendas conviene realizar la venta?

Para ello, se desarrollaron los siguientes pasos analíticos:

1. **Análisis de facturación por sucursal**  
   Se calculó el total de ingresos generados por cada tienda para identificar las de mayor rendimiento.

2. **Ventas por categoría de producto**  
   Se identificaron los tipos de productos más vendidos en cada sucursal y su contribución a la facturación total.

3. **Calificaciones promedio de los usuarios**  
   Se calcularon las valoraciones promedio para evaluar la satisfacción del cliente en cada tienda.

4. **Productos más y menos vendidos**  
   Se determinaron los artículos más populares y aquellos con bajo movimiento para entender las preferencias del mercado.

5. **Cálculo de costos de envío promedio**  
   Se estimaron los gastos logísticos de cada sucursal para analizar su impacto en la rentabilidad.

6. **Visualizaciones**  
   Se generaron gráficos informativos y comparativos que permiten comprender de forma clara las diferencias entre tiendas.

7. **Conclusión y justificación de la decisión**  
   Dentro del archivo de Google Colab se incluye una **justificación final sobre qué sucursal se recomienda para realizar la venta**, basada en datos cuantitativos y cualitativos.
